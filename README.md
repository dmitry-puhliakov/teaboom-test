# 🍵 Тестовое задание: Карточка товара (Teaboom)

🔗 **[Смотреть рабочую демку (GitHub Pages)](https://dmitry-puhliakov.github.io/teaboom-test/)**

## 🚀 О проекте
Адаптивная верстка и логика карточки товара для интернет-магазина.
Проект выполнен **без использования сторонних UI-библиотек (в т.ч. Bootstrap, jQuery, Swiper)**. Только нативные браузерные API и строгий контроль производительности.

### ✨ Реализованные фичи (Zero Dependencies)
- 🛒 **Динамический пересчет** — логика переключения фасовок (цена, артикул, старая цена) реализована через единый стейт и делегирование событий.
- 🖼️ **Нативный свайпер галереи** — горизонтальный скролл картинок реализован на чистом CSS (`scroll-snap`), что обеспечивает аппаратное ускорение и стабильные 60 FPS на мобильных устройствах без JS-оверхеда.
- 🔍 **Модульный Lightbox** — просмотр увеличенных фотографий с плавными CSS-транзициями и закрытием по клику на overlay/кнопку Escape.
- 🔔 **Универсальная Toast-система** — кастомная неблокирующая система уведомлений («Товар добавлен в корзину»), работающая через data-атрибуты.
- 📱 **Off-canvas сайдбар** — мобильное меню с блокировкой скролла фона (`body scroll lock`).

## 🛠️ Стек технологий
- **HTML5**: Семантическая разметка (`<article>`, `<aside>`, `<main>`, `<figure>`).
- **SCSS**: БЭМ-нейминг, модульная структура, Flexbox/Grid layout.
- **Vanilla JavaScript (ES6+)**: Разделение на независимые ES-модули, минимизация обращений к DOM, отсутствие утечек памяти.
- **Vite**: Быстрая сборка проекта и dev-сервер.
